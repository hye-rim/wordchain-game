# 끝말잇기

앞 단어의 끝 글자로 시작하는 말을 이어 가는 끝말잇기. — [작은 오락실](https://github.com/hye-rim/smallgame) 게임

## 규칙

- 두 글자 이상 명사, 한 번 나온 말은 다시 못 써요
- 두음법칙 OK: 력→역, 리→이, 라→나, 로→노, 녀→여, 뉴→유
- 이을 말이 아예 없는 **한방 단어**(기쁨, 부엌, 슬픔…)를 쓰면 다음 사람이 바로 져요

## 모드

- **컴퓨터와 이어가기**: 이을 때마다 점수(긴 말·빠른 답·흔치 않은 말 보너스, 연속 배율). 하트 3개, 패스 2번.
  길게 이을수록 제한 시간이 줄고(18초 → 8초), 컴퓨터가 잇기 어려운 끝 글자를 내요.
  컴퓨터가 못 이으면 한방 보너스 +500. 컴퓨터는 한방 단어를 쓰지 않아요.
- **온라인 대결**: 2~6명이 방 코드나 초대 링크(`?room=코드`)로 모여 돌아가며 이어요. 차례마다 15초(단어가 쌓일수록 7초까지 줄어듦),
  시간 초과는 패, 패 3개면 탈락, 마지막까지 남으면 우승. 빠른 대전(2명 자동 매칭)도 있어요. 새로고침·잠깐 끊김은 자리를 지켜 줘요.

## 실행

```bash
npm install
npm start        # PORT 환경변수로 포트 지정 (기본 3006)
```

작은 오락실 로비에서는 서버 게임으로 함께 실행되며 `/wordchain/` 아래로 연결돼요.

## 사전

`data/words.txt`(판정용 2~8글자 명사 19만여 개), `data/common.txt`(자주 쓰는 명사: 시작 단어·컴퓨터의 말·예시).
[han-dle/pd-korean-noun-list-for-wordles](https://github.com/han-dle/pd-korean-noun-list-for-wordles)(CC0)를 가공한 것으로,
원 출처는 표준국어대사전(2018)과 한국어 학습용 어휘(2019)예요. 자세한 내용은 `data/NOTICE.txt`.
